# 🚀 Go Fundamentals

**Learn Go step by step through practical examples and hands-on coding.**

Welcome to **Go Fundamentals**! 👋 This repository is designed to help developers understand the core concepts of Go (Golang) through simple explanations and practical examples.

Whether you're starting with Go or reviewing the fundamentals, this repository is a place to learn, practice, and grow.

## 📚 What's Inside?

This repository covers Go fundamentals through organized folders and practical examples.

- Variables and Data Types
- Conditions and Loops
- Functions
- Arrays, Slices, and Maps
- Structs and Pointers
- Error Handling
- More topics coming soon!

## ⭐ Getting Started

### 1. Install Go

Download and install Go from the official website:

👉 https://go.dev/dl/

Verify your installation:

```bash
go version
```

### 2. Clone the Repository

Clone this repository to your local machine:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project folder:

```bash
cd YOUR_REPOSITORY_NAME
```

> Replace `YOUR_REPOSITORY_URL` with your GitHub repository URL and `YOUR_REPOSITORY_NAME` with the cloned folder name.

### 3. Open the Project in VS Code

```bash
code .
```

If the `code` command is unavailable, open VS Code manually and select **File → Open Folder**, then choose the cloned repository folder.

## ▶️ How to Run the Examples

**Important:** Open the specific folder or navigate to the directory containing the Go file you want to run.

For example, if your repository is organized like this:

```text
go-fundamentals/
├── 01-variables/
│   └── main.go
├── 02-conditions/
│   └── main.go
├── 03-loops/
│   └── main.go
└── README.md
```

To run the variables example:

```bash
cd 01-variables
go run main.go
```

To run the conditions example, return to the root folder and navigate to the next directory:

```bash
cd ..
cd 02-conditions
go run main.go
```

**Alternative:** Open the desired folder directly in VS Code, open its terminal, and run:

```bash
go run main.go
```

> Run the command from the directory containing the relevant Go file. If an example uses multiple `.go` files in the same package, you may need to run `go run .` from a properly configured Go module directory.

## 🍴 Fork This Repository

Forking creates your own copy of this repository on GitHub.

1. Open this repository on GitHub.
2. Click **Fork** in the top-right corner.
3. Choose your GitHub account.
4. Clone your fork to your computer:

```bash
git clone YOUR_FORK_URL
```

5. Open the project and start experimenting!

## 💻 Clone Without Forking

If you only want to download the project and run the examples:

1. Open the repository on GitHub.
2. Click **Code → HTTPS**.
3. Copy the repository URL.
4. Run:

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_REPOSITORY_NAME
code .
```
